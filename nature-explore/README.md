# Sanoj Kumar — Nature Explore

A responsive nature discovery website featuring landscapes, wildlife, an image gallery and simple conservation guidance.

## Preview locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)` if Pages is not already enabled.
4. Save. The site is available at:

`https://sanojkumar891.github.io/sanohkumar/nature-explore/`

The website uses externally hosted Unsplash images and requires an internet connection to load them.
